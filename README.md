# Music Listening Habits Analysis

## Project Description

This project focuses on analyzing music listening habits across different streaming platforms using Python. It aims to understand user listening behavior, identify music preferences, and compare platform usage through data analysis and visualization.

## Objectives

- Clean and prepare the dataset using Pandas and NumPy.
- Analyze listening habits by hour and day of the week.
- Identify the most listened-to music genres.
- Compare music listening behavior across different platforms.
- Calculate listening duration statistics.
- Create visualizations using Matplotlib and Seaborn.
- Export the analysis results to a CSV file.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Features

- Data cleaning and preprocessing.
- Analysis of listening habits by hour and weekday.
- Identification of favorite music genres.
- Comparison of listening platforms.
- Analysis of average listening duration.
- Data visualization through charts and a heatmap.
- Export of statistical results to a CSV file.

## Installation and Execution

### 1. Clone the repository

```bash
git clone https://github.com/Medrayanebens/music-listening-analysis.git
cd music-listening-analysis
```

### 2. Install the required libraries

```bash
pip install -r requirements.txt
```

### 3. Run the project

```bash
python main.py
```
